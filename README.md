# Jokura et al
Repository for data, code and text of the Jokura et al paper on NO signalling in Platynereis larvae


Kei Jokura, Nobuo Ueda, Martin Gühmann, Luis Alfonso Yañez-Guerra, Piotr Słowiński, Kyle C. A. Wedgwood, Gáspár Jékely. Nitric oxide feedback to ciliary photoreceptor cells gates a UV avoidance circuit. eLife12:RP91258 https://elifesciences.org/reviewed-preprints/91258

To reproduce the analyses, download the repository and open the Jokura_et_al_NOS/Jokura_et_al_NOS.Rproj R project file in Rstudio. Each figure has its own code in /code
